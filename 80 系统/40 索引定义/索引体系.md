# 索引体系

## MOC 与索引的区别

- MOC 解释知识结构和学习路径；
- 索引提供快速检索入口，尽量保持简洁；
- Manifest 管理尚未实例化的建设计划。

## 全局索引

计划维护：

```text
术语索引
公式索引
算法索引
API 索引
Shader 索引
实验索引
性能案例索引
故障案例索引
来源索引
```

## 收录原则

- 只收录值得主动回访的稳定入口；
- 不复制文章摘要和正文；
- 一个条目可以出现在多个横向索引；
- 条目标题使用正式文章标题；
- 过时内容明确标记替代文章。

## 索引生成策略

第一阶段手工维护核心索引。文章数量增长后，再由脚本根据 `type`、`domain`、`id`、`apis`、`platforms` 等 Properties 生成候选列表，人工确认后写入正式索引。
