# 成熟度与验证规则

## 内容成熟度

| 状态 | 含义 |
|---|---|
| seed | 只有问题、线索或想法 |
| outline | 已形成文章结构 |
| draft | 已有主体内容，但仍需补全 |
| stable | 结构和结论相对稳定 |
| evergreen | 经长期使用、多次修订和复核 |

## 验证状态

| 状态 | 含义 |
|---|---|
| unverified | 尚未验证 |
| source-checked | 已核对可靠来源 |
| derived | 已完成公式或逻辑推导 |
| experiment-reproduced | 已通过可复现实验验证 |
| production-validated | 已在实际工程环境验证 |

## 生命周期

| 状态 | 含义 |
|---|---|
| active | 当前有效 |
| needs-update | 内容需要更新 |
| deprecated | 已过时但保留历史链接 |
| archived | 不再参与日常维护 |

示例：

```yaml
maturity: stable
verification: experiment-reproduced
lifecycle: active
```
