# 链接与来源规则

## 正文关系

成熟知识文章优先在正文中显式维护：

- 前置知识
- 上层应用
- 对比与边界
- 实现与实验
- 来源

不要求在 Frontmatter 中维护庞大的 `related` 列表。

## 来源规则

1. 来源笔记与正式知识分离；
2. 一本书可以支持多个正式知识文章；
3. 正式文章应记录关键来源；
4. 数学结论需要来源或完整推导；
5. API 和平台文章需要官方文档与版本信息；
6. 工程经验应标记实验或生产验证环境；
7. 过时文章使用 `deprecated` 和 `superseded_by`，不直接破坏历史链接。

## 唯一基础解释

基础理论只维护一个完整主版本；领域应用文章通过链接复用基础理论，不重新复制整段定义与推导。
