# 自动化与脚本

## 当前脚本

仓库根目录提供：

```bash
python scripts/validate_kb.py
```

当前检查：

- Markdown Frontmatter 是否闭合；
- 核心目录中的必填属性；
- 文章 `id` 是否重复；
- 内部 Wikilink 是否失效或存在歧义；
- 空文章和异常短文章提示。

## 原则

- 默认只依赖 Python 标准库；
- 校验错误应阻止 PR 合并；
- 警告用于提示改进，不阻止提交；
- 自动生成内容必须可审阅，不直接覆盖人工正文；
- 所有批量迁移先输出报告，再执行写入。

## 后续计划

- 来源覆盖率统计；
- 孤立文章检查；
- MOC 覆盖率检查；
- 版本敏感文章更新报告；
- 旧路径和 `legacy_id` 迁移报告。
