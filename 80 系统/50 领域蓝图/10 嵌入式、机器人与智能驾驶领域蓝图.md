# 10 嵌入式、机器人与智能驾驶领域蓝图

## 1. 领域目标

维护从端侧硬件、实时系统、传感器、状态估计、机器人中间件到定位、地图、感知、规划、控制和智能驾驶系统集成的完整领域知识。

## 2. 主归属边界

进入本领域：

- MCU、SoC、RTOS、总线、传感器和执行器的领域应用；
- 机器人坐标、状态估计、ROS、定位、SLAM 和地图；
- 感知、预测、规划、控制和智能驾驶系统接口；
- 端侧部署、实时约束、功能安全和三维可视化集成。

不进入本领域：

- 位姿、概率、优化和控制的一般数学 → 数学／物理；
- 图搜索、实时调度和体系结构一般原理 → 计算机科学；
- Linux、交叉编译和驱动环境本身 → 系统与平台；
- 点云、地图和车辆的通用渲染算法 → 图形学；
- 具体引擎中的可视化对象和 UI → 游戏引擎与实时应用；
- 感知模型的一般训练方法 → AI。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| ROBO-EMB | 嵌入式基础 | MCU、寄存器、中断、内存、外设和低功耗 |
| ROBO-SOC | SoC 与端侧计算 | ARM、GPU/NPU、内存、异构计算和 RK3588 等平台 |
| ROBO-RTOS | RTOS 与实时系统 | 任务、调度、同步、时间约束和资源隔离 |
| ROBO-BUS | 总线与通信 | UART、SPI、I2C、CAN、Ethernet 和车载通信 |
| ROBO-SENSOR | 传感器与执行器 | Camera、IMU、GNSS、LiDAR、Radar、电机和标定 |
| ROBO-EST | 状态估计 | Bayes Filter、Kalman、粒子滤波、融合和不确定性 |
| ROBO-ROS | ROS 与机器人中间件 | Node、Topic、Service、TF、Bag、DDS 和生命周期 |
| ROBO-FRAME | 坐标、时间与标定 | Frame、外参、时间同步、TF 树和多传感器对齐 |
| ROBO-LOC | 定位与 SLAM | 视觉／激光 SLAM、地图匹配、回环和优化 |
| ROBO-MAP | 地图与场景模型 | HD Map、栅格、拓扑、语义地图和地图服务 |
| ROBO-PER | 感知 | 检测、分割、跟踪、融合和 Occupancy |
| ROBO-PRED | 预测 | 轨迹预测、交互建模和不确定性 |
| ROBO-PLAN | 规划与决策 | 搜索、采样、行为规划、运动规划和约束 |
| ROBO-CTRL | 控制 | PID、LQR、MPC、轨迹跟踪和执行器控制 |
| ROBO-AD | 智能驾驶系统 | 数据流、域控制器、接口、场景和系统架构 |
| ROBO-VIZ | 可视化与 HMI | 地图、车体、路线、点云、感知和小屏显示 |
| ROBO-DEPLOY | 端侧部署与性能 | 交叉编译、模型部署、实时性、内存和功耗 |
| ROBO-SAFE | 安全、诊断与测试 | 功能安全、故障诊断、仿真、回放和场景测试 |

## 4. 核心基础

- 数学：位姿、概率、优化、数值方法和信号；
- 物理：传感器、车辆动力学、控制和测量；
- 计算机科学：实时系统、网络、图搜索和并发；
- AI：视觉感知、预测和模型部署；
- 图形学：坐标、点云、地图和实时可视化；
- 系统平台：Linux、SoC、驱动、交叉编译和设备诊断。

## 5. 典型应用

- ROS 机器人系统和智能轮椅；
- 智能驾驶地图、定位、感知和规划链路；
- 车载 3D 场景、480×480 小屏和 HMI；
- 点云、路线、车辆和感知框可视化；
- RK3588 等端侧 GPU／NPU 部署；
- 数据回放、仿真、日志和场景测试。

## 6. 来源与证据

优先来源：芯片与传感器手册、ROS／DDS 官方文档、机器人教材、标准、原始论文、数据集、Bag／日志和真实设备实验。

验证方式：

- 精确硬件、固件、时间和坐标记录；
- Bag 回放、仿真和真实传感器对照；
- 定位误差、感知指标、规划成功率和控制误差；
- 实时性、抖动、内存、功耗和故障注入；
- 场景覆盖、回归和安全边界检查；
- 可视化结果与原始数据一致性。

## 7. 实验与实践

- ROS Topic／TF／Bag 和时间同步实验；
- Camera、IMU、LiDAR 外参和标定；
- EKF、粒子滤波和状态融合 Demo；
- 2D／3D SLAM 和地图构建；
- A*、Dijkstra、采样和轨迹优化；
- PID／LQR／MPC 控制模拟；
- 点云、路径和感知三维可视化；
- 端侧部署、性能和故障恢复测试。

## 9. 跨领域关系

- ← 数学／物理：位姿、估计、控制、传感和车辆模型；
- ← 计算机科学：实时、网络、图搜索和空间算法；
- ↔ AI：感知、预测和端侧模型；
- ↔ 系统平台：SoC、Linux、驱动和交叉编译；
- ↔ 图形学：点云、地图、路线和渲染；
- ↔ 游戏引擎：仿真、可视化和交互框架；
- ↔ 软件工程：模块、通信、日志、测试和可靠性。

## 10. 首批建设建议

1. ROS 通信、TF、时间戳和 Bag 回放；
2. 坐标、标定、状态估计和定位基础；
3. 地图、路线、点云和感知数据模型；
4. 智能驾驶三维可视化和小屏设计；
5. 规划、控制和车辆系统总览；
6. RK3588／端侧部署和性能；
7. 再扩展 SLAM、感知和安全测试。

## 11. 非目标

- 不复制数学、图形学和 AI 的完整基础教程；
- 不把一次设备测试结果推广到所有硬件；
- 不在公开仓库保存公司机密数据、地图、日志和接口；
- 不在无场景、时间和坐标定义时讨论系统正确性；
- 不用可视化画面代替定位、感知和规划数据验证。
