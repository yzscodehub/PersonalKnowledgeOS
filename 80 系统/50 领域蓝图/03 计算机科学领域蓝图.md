# 03 计算机科学领域蓝图

## 1. 领域目标

维护计算、信息、算法和计算机系统的一般原理，解释“为什么可以计算、如何组织计算、复杂度和资源边界是什么”，为软件工程、图形学、AI、音视频和系统平台提供通用理论基础。

## 2. 主归属边界

进入计算机科学：

- 数据结构、算法、复杂度和可计算性；
- 体系结构、操作系统、网络、数据库和编译原理；
- 并行、分布式、安全和信息理论的一般模型；
- 与具体业务、框架和平台无关的计算原理。

不进入计算机科学：

- 现代 C++ 项目组织和测试实践 → 软件工程；
- Windows、Linux、驱动和工具链操作 → 系统与平台；
- GPU 图形管线和渲染算法 → 图形学；
- UE5 TaskGraph 的源码和用法 → 游戏引擎；
- 具体模型训练和推理工程 → AI。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| CS-FND | 计算与信息基础 | 计算模型、编码、信息量、可计算性 |

| CS-COMP | 复杂度与算法分析 | 时间空间复杂度、摊还、下界、近似 |
| CS-ARCH | 计算机体系结构 | 指令、缓存、内存层次、流水线、GPU 基础 |
| CS-OS | 操作系统原理 | 进程、线程、调度、虚拟内存、文件系统 |
| CS-NET | 计算机网络 | 分层、传输、路由、拥塞、实时网络 |
| CS-PL | 程序语言与编译 | 类型、语义、编译器、链接和运行时 |
| CS-DB | 数据库与存储系统 | 数据模型、索引、事务、查询和日志 |
| CS-DIST | 分布式系统 | 一致性、复制、共识、容错、时间与顺序 |
| CS-PAR | 并行与并发计算 | 同步、内存模型、任务图、SIMD/SIMT |
| CS-SEC | 计算机安全基础 | 威胁模型、密码学基础、访问控制和漏洞原理 |

| CS-HCI | 人机交互基础 | 输入、反馈、认知负担、交互模型和可用性 |

## 4. 核心基础

- 离散数学、图论、概率和逻辑；
- 算法分析和数据表示；
- 体系结构、内存和并发；
- 抽象、接口和状态机；
- 正确性、复杂度和资源权衡。

## 5. 典型应用

- 渲染器中的 BVH、任务图、缓存和并行调度；
- AI 系统中的数据结构、分布式训练和推理服务；
- 音视频中的缓冲、网络、同步和实时调度；
- 引擎中的 ECS、资源系统和增量构建；
- 机器人中的路径规划、图搜索和实时系统；
- 软件性能、数据库和网络架构分析。

## 6. 来源与证据

优先来源：权威教材、标准、经典论文、算法原始论文和高质量课程。

验证方式：

- 正确性证明和复杂度分析；
- 参考实现与单元测试；
- 模拟、可视化和对照实验；
- 并发不变量、模型检查或压力测试；
- 体系结构 Counter 和受控基准。

## 7. 实验与实践

- 实现核心数据结构和算法；
- 比较缓存友好与非缓存友好布局；
- 构建线程池、任务图和同步实验；
- 编写小型编译器或解释器；
- 模拟数据库事务、日志和恢复；
- 实现简化分布式协议和故障注入；
- 构建 BVH、KD 树和空间查询实验。

## 8. 核心 MOC

计划维护：

```text
计算机科学总览
算法、数据结构与复杂度 MOC
体系结构、缓存与内存 MOC
操作系统与并发 MOC
程序语言、编译与运行时 MOC
网络与分布式系统 MOC
计算几何与空间数据结构 MOC
```

## 9. 跨领域关系

- ← 数学：离散、概率、逻辑和数值基础；
- → 软件工程：把一般原理转化为可维护系统；
- → 系统平台：映射到具体 OS、硬件和工具链；
- → 图形学：几何算法、GPU 架构和并行计算；
- → AI：算法、数据、分布式和系统基础；
- → 游戏引擎：对象系统、任务系统和资源管理；
- → 音视频／机器人：实时调度、网络和空间算法。

## 10. 首批建设建议

1. 数据结构、算法分析和缓存友好设计；
2. 体系结构、内存层次和 GPU 并行基础；
3. 并发、内存模型、线程池和任务图；
4. 操作系统、网络和实时调度基础；
5. 计算几何、BVH、KD 树和图搜索；
6. 再扩展编译、数据库、分布式和安全。

## 11. 非目标

- 不把具体语言风格和项目流程混入通用原理；
- 不为每个平台复制操作系统原理；
- 不用 LeetCode 题目数量代替算法体系；
- 不只写抽象理论而缺少参考实现；
- 不将具体引擎、API 或产品实现作为普遍规律。
