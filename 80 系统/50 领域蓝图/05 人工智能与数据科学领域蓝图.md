# 05 人工智能与数据科学领域蓝图

## 1. 领域目标

维护从数据、模型、训练、评估到推理和应用系统的完整知识，覆盖传统机器学习、深度学习、大语言模型、生成模型、RAG、Agent、多模态和 AI 工程。

## 2. 主归属边界

进入本领域：

- 数据表示、特征、监督／无监督学习和模型评估；
- 神经网络、训练、优化、推理和生成模型；
- LLM、RAG、Agent、多模态和 AI 应用系统；
- 模型部署、推理性能、数据治理和 AI 安全。

不进入本领域：

- 与应用无关的概率、优化和线性代数 → 数学；
- 分布式系统和 GPU 一般原理 → 计算机科学；
- 通用服务架构、测试和 CI → 软件工程；
- CUDA 驱动、平台部署和设备排障 → 系统与平台；
- NeRF／3DGS 的渲染表示和画面生成机制 → 图形学应用文章。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| AI-FND | AI 与数据基础 | 问题类型、数据、偏差、训练和评估基本概念 |
| AI-ML | 传统机器学习 | 线性模型、树模型、核方法、聚类和降维 |
| AI-DL | 深度学习 | 网络、反向传播、正则化、优化和训练稳定性 |
| AI-CV | 计算机视觉 | 分类、检测、分割、几何视觉和视觉表示 |
| AI-NLP | NLP 与语言模型基础 | Token、Embedding、Transformer、语言建模 |
| AI-LLM | 大语言模型 | 预训练、微调、对齐、推理、上下文和评估 |
| AI-GEN | 生成模型 | VAE、GAN、Diffusion、Flow 和生成式建模 |
| AI-RAG | 检索增强生成 | 索引、检索、重排、上下文构建和评估 |
| AI-AGENT | Agent 与工具使用 | 规划、工具、记忆、多 Agent、权限和可靠性 |
| AI-MM | 多模态 | 文本、图像、音频、视频和三维联合表示 |
| AI-DATA | 数据工程与治理 | 采集、清洗、标注、版本、质量和隐私 |
| AI-EVAL | 模型与系统评估 | 指标、基准、人工评测、回归和风险评估 |
| AI-INFER | 推理与服务 | 量化、蒸馏、缓存、批处理、Serving 和成本 |
| AI-SAFE | 安全、对齐与治理 | 鲁棒性、滥用、可解释性、隐私和责任边界 |

## 4. 核心基础

- 线性代数、概率统计、优化和数值分析；
- 数据结构、体系结构、并行和分布式系统；
- 软件工程、测试、服务设计和可观测性；
- 领域数据和任务定义；
- 评估、实验设计和因果意识。

## 5. 典型应用

- 个人知识库的检索、问答和自动整理；
- 代码辅助、智能 Agent 和工程自动化；
- 图像、视频、音频和三维内容生成；
- 智能驾驶感知、预测和数据闭环；
- 搜索、推荐、分类和异常检测；
- 模型压缩、端侧推理和多模态交互。

## 6. 来源与证据

优先来源：原始论文、官方模型卡、框架文档、公开数据集、评测报告和可复现代码。

验证方式：

- 固定数据划分和基线；
- 离线指标、人工评测和错误分析；
- 消融实验和对照实验；
- 成本、延迟、吞吐和资源测量；
- 数据泄漏、偏差和安全测试；
- 生产反馈和持续回归。

## 7. 实验与实践

- 从零实现基础模型和训练循环；
- 建立小型分类、生成和检索项目；
- 构建可评估的 RAG 管线；
- Agent 工具调用、权限和失败恢复实验；
- 量化、蒸馏、KV Cache 和批处理对比；
- 多模态生成和内容工作流；
- 建立数据、Prompt、模型和评估版本记录。

## 8. 核心 MOC

计划维护：

```text
人工智能与数据科学总览

生成模型与多模态 MOC

```

## 9. 跨领域关系

- ← 数学：概率、优化、线性代数和采样；
- ← 计算机科学：算法、架构、分布式和数据库；
- ↔ 软件工程：应用架构、测试、评估和交付；
- ↔ 系统平台：GPU、驱动、容器和模型服务；
- ↔ 图形学：神经渲染、图像生成和三维表示；
- ↔ 音视频：语音、视频理解和多模态；
- ↔ 机器人与智能驾驶：感知、预测和端侧部署；
- → 设计与内容：AIGC 生产工作流。

## 10. 首批建设建议

1. 建立机器学习、深度学习和 Transformer 基础；
2. 建立评估、数据划分和实验治理；
3. 实现代码级 RAG，连接个人知识库；
4. 建立 Agent 工具调用、权限和失败恢复；
5. 建立推理成本、量化和部署基础；
6. 再扩展 Diffusion、多模态和领域模型。

## 11. 非目标

- 不按热门模型名称建立短命目录；
- 不只记录 Prompt 和产品用法而缺少模型与评估基础；
- 不把单次 Demo 效果当作系统可靠性；
- 不在没有评估集和失败分析时声称方案更好；
- 不把通用软件、平台和数学知识复制到 AI 目录。
