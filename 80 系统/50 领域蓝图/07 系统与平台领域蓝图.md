# 07 系统与平台领域蓝图

## 1. 领域目标

维护软件在具体操作系统、硬件、驱动、工具链、运行环境和部署平台中的实际行为，形成可复现的配置、诊断、兼容性和恢复知识。

## 2. 主归属边界

进入本领域：

- Windows、Linux、macOS、WSL 和虚拟化环境；
- CPU、GPU、存储、网络设备和驱动能力；
- 编译器、链接器、调试器、Profiler 和开发工具链；
- CUDA、DirectML、VideoToolbox、DXVA 等平台能力；
- 安装、配置、部署、环境变量、权限和平台排障。

不进入本领域：

- 操作系统和体系结构的一般原理 → 计算机科学；
- 通用构建、测试和交付方法 → 软件工程；
- 图形 API 的渲染语义 → 图形学；
- FFmpeg 编解码和媒体同步 → 音视频；
- UE5、Qt 或 Unity 的框架对象模型 → 游戏引擎。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| SYS-WIN | Windows | 进程、服务、注册表、WMI、图形栈和诊断 |
| SYS-LINUX | Linux | 发行版、systemd、权限、网络、包管理和诊断 |
| SYS-MAC | macOS 与 Apple 平台 | Xcode、Metal 环境、签名、沙箱和系统工具 |
| SYS-WSL | WSL 与混合环境 | 文件系统、网络、代理、GPU 和跨环境工具 |
| SYS-VIRT | 虚拟化与容器 | VirtualBox、VMware、Hyper-V、Docker 和隔离 |
| SYS-CPU | CPU 与内存平台 | ISA、NUMA、内存、温度、固件和平台能力 |
| SYS-GPU | GPU、驱动与计算平台 | 驱动、CUDA、图形栈、设备能力和故障 |
| SYS-STOR | 存储与文件系统 | SSD、文件系统、WAL、备份介质和 I/O 诊断 |
| SYS-NET | 网络环境与代理 | DNS、路由、代理、VPN、抓包和连接诊断 |
| SYS-TOOL | 编译、链接与调试工具链 | MSVC、Clang、GCC、LLDB、GDB、符号和崩溃 |
| SYS-DEPLOY | 运行时与部署环境 | 包、服务、权限、配置、签名和环境隔离 |
| SYS-HW | 设备、固件与稳定性 | BIOS、内存、主板、传感器、功耗和兼容性 |
| SYS-REC | 系统恢复与数据保护 | 快照、镜像、备份、灾难恢复和误操作处理 |

## 4. 核心基础

- 计算机体系结构、操作系统和网络原理；
- 文件、进程、权限、环境和设备模型；
- 编译、链接、符号和调试基础；
- 日志、Counter、Trace 和最小复现；
- 备份、回滚和变更控制。

## 5. 典型应用

- 搭建 C++、图形、AI 和音视频开发环境；
- GPU 驱动、硬件编码和计算平台诊断；
- Windows／macOS 跨平台发布；
- WSL、虚拟机和远程 Linux 开发；
- 网络代理、SSH、Git 和云服务连接；
- 磁盘、数据库日志、内存和系统稳定性排查。

## 6. 来源与证据

优先来源：操作系统和硬件官方文档、驱动 Release Notes、工具链文档、设备规格、日志、Trace 和最小复现。

验证方式：

- 记录精确版本、硬件和配置；
- 命令输出、日志和系统 Counter；
- 修改前后对照；
- 干净环境或虚拟机复现；
- 回滚和恢复测试；
- 区分规范能力、厂商实现和本机观察。

## 7. 实验与实践

- 建立可重建的 Windows／Linux／macOS 开发环境；
- 编译器和链接器最小实验；
- WSL、虚拟机、容器网络和文件 I/O 对比；
- GPU 驱动、CUDA、图形 API 能力探测；
- 日志、Crash Dump、Trace 和性能 Counter 分析；
- 备份、恢复、误删和配置回滚演练。

## 8. 核心 MOC

计划维护：

```text
系统与平台总览
Windows 开发与诊断 MOC
Linux、WSL 与远程开发 MOC
macOS、Xcode 与 Apple 平台 MOC
GPU、驱动与计算平台 MOC
编译、链接、符号与调试 MOC
虚拟化、容器与环境隔离 MOC
网络、代理与远程连接 MOC
存储、备份与系统恢复 MOC
```

## 9. 跨领域关系

- ← 计算机科学：体系结构、OS、网络和编译原理；
- ↔ 软件工程：构建、交付、可观测和恢复方法；
- → 图形学：GPU、驱动、图形 API 和 Capture 工具环境；
- → AI：CUDA、模型运行时、容器和推理设备；
- → 音视频：硬件编解码、设备、驱动和平台媒体框架；
- → 游戏引擎：引擎构建、打包和平台适配；
- → 嵌入式：SoC、Linux、交叉编译和设备部署。

## 10. 首批建设建议

1. Windows、Linux、macOS 三平台开发环境和诊断入口；
2. MSVC、Clang、CMake、符号和崩溃调试；
3. GPU 驱动、CUDA、RenderDoc／PIX／Xcode 工具链；
4. WSL、SSH、代理和远程开发；
5. 存储、日志、备份和恢复；
6. 再扩展虚拟化、容器和嵌入式 Linux 环境。

## 11. 非目标

- 不复制操作系统教材中的全部一般原理；
- 不把一次本机现象推广为所有设备规律；
- 不保存无版本、无环境的命令片段；
- 不把通用软件架构和领域算法混入平台笔记；
- 不在公开仓库记录密钥、私人路径、内部地址和机密日志。
