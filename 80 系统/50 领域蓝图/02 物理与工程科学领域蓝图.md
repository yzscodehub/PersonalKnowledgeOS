# 02 物理与工程科学领域蓝图

## 1. 领域目标

维护描述现实世界的物理规律、工程近似、系统模型、量纲关系和控制基础，为渲染、模拟、机器人、音视频、硬件和智能驾驶提供可复用的现实模型。

## 2. 主归属边界

进入本领域：

- 力学、光学、电磁、热学、声学和连续介质规律；
- 工程建模中的假设、量纲、守恒和近似；
- 控制系统、状态空间和系统响应的工程科学基础；
- 与具体软件平台无关的传感器、执行器和物理系统模型。

不进入本领域：

- 光照方程的渲染近似和 BRDF 实现 → 图形学；
- 具体物理引擎 API → 游戏引擎与实时应用；
- ROS 控制节点和车辆控制系统集成 → 机器人与智能驾驶；
- 数值 PDE 求解器的通用算法 → 数学或计算机科学。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| PHYS-MECH | 经典力学 | 运动学、动力学、刚体、能量与动量 |
| PHYS-CONT | 连续介质与流体 | 应力应变、流体、弹性、波动 |
| PHYS-THERM | 热学与热力学 | 温度、热传导、能量转换 |
| PHYS-EM | 电磁学 | 电场、磁场、电路与电磁波 |
| PHYS-OPT | 光学 | 几何光学、波动光学、辐射度学基础 |
| PHYS-ACOU | 声学 | 声波、传播、反射、吸收和空间声学 |
| PHYS-CTRL | 控制理论 | 反馈、稳定性、状态空间、离散控制 |
| PHYS-MEAS | 测量与传感 | 误差、标定、噪声、传感器模型 |
| PHYS-SYS | 工程系统建模 | 方框图、传递函数、量纲和近似 |
| PHYS-MAT | 材料与制造基础 | 材料性质、加工、结构和制造约束 |

## 4. 核心基础

- 向量分析、微积分和微分方程；
- 量纲分析、守恒定律和误差传播；
- 线性系统、频域和状态空间；
- 实验设计、测量和不确定性。

## 5. 典型应用

- 物理渲染中的光传输和材料模型；
- 刚体、布料、流体和粒子模拟；
- 相机、IMU、雷达和激光雷达模型；
- 车辆动力学、机器人控制和定位；
- 声学、麦克风和扬声器系统；
- 散热、电源和嵌入式硬件设计理解。

## 6. 来源与证据

优先来源：经典教材、工程手册、标准、原始论文、实验数据和设备规格。

验证方式：

- 量纲和极限情况检查；
- 实验测量与模型预测比较；
- 守恒量和稳定性检查；
- 仿真与真实数据对照；
- 明确模型假设和适用尺度。

## 7. 实验与实践

- 简单摆、刚体和阻尼系统模拟；
- 光线折射、反射和辐射度量实验；
- 传感器噪声和标定实验；
- PID、状态反馈和离散控制模拟；
- 声波采样与频响测量；
- 热传导和材料参数的数值对照。

## 8. 核心 MOC

计划维护：

```text
物理与工程科学总览
力学与实时模拟 MOC
光学、辐射度学与成像 MOC
传感器、测量与标定 MOC
控制理论与状态空间 MOC
声学与音频系统 MOC
```

## 9. 跨领域关系

- ← 数学：微积分、ODE/PDE、概率、信号和数值分析；
- → 图形学：光传输、材质、动画和模拟；
- → 音视频：声学、采样和传感；
- → 机器人与智能驾驶：车辆、传感器、控制和估计；
- → 系统平台：设备、驱动和硬件能力；
- → 游戏引擎：物理引擎中的工程应用。

## 10. 首批建设建议

1. 建立几何光学、辐射度量和成像基础；
2. 建立刚体运动学、动力学和碰撞基础；
3. 建立传感器误差、噪声和标定基础；
4. 建立反馈控制和状态空间基础；
5. 按机器人、音视频和模拟项目需要扩展声学、流体和材料。

## 11. 非目标

- 不建设完整大学物理百科；
- 不把具体引擎或硬件 API 放在物理主文章；
- 不忽略模型假设而把近似当作普遍定律；
- 不在缺少实验或应用目标时批量整理公式；
- 不取代安全关键工程中的正式标准和专业评审。
