# 09 音视频与多媒体领域蓝图

## 1. 领域目标

维护音频、视频和实时媒体从表示、采集、编解码、封装、处理、同步、播放到传输的完整知识，并连接硬件加速、GPU 处理和跨平台媒体系统。

## 2. 主归属边界

进入本领域：

- 采样、PCM、YUV、色度抽样、时间戳和时基；
- 音视频编解码、容器、复用、解复用和转码；
- 播放器、滤镜、同步、缓冲、Seek 和 Frame Scheduling；
- WebRTC、实时传输、抖动、丢包和拥塞控制；
- FFmpeg、硬件编解码和媒体管线的领域语义。

不进入本领域：

- 信号与傅里叶分析的一般推导 → 数学；
- 声学和传感器物理 → 物理与工程科学；
- 网络、调度和缓冲的一般原理 → 计算机科学；
- CUDA、VideoToolbox、DXVA 驱动和平台配置 → 系统与平台；
- 通用异步架构、资源生命周期和测试方法 → 软件工程。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| MEDIA-FND | 媒体基础与表示 | 采样、量化、帧、声道、像素格式和时基 |
| MEDIA-AUDIO | 音频 | PCM、重采样、声道、音量、混音和处理 |
| MEDIA-VIDEO | 视频 | YUV、色度抽样、帧结构、颜色和画面格式 |
| MEDIA-CODEC | 编解码 | 熵编码、预测、变换、码率控制和 Codec |
| MEDIA-CONT | 容器与封装 | MP4、MKV、TS、索引、Metadata 和 Seek |
| MEDIA-TIME | 时间戳与同步 | PTS/DTS、Clock、AV Sync、漂移和调度 |
| MEDIA-FILTER | 滤镜与格式转换 | Scale、Resample、Color Convert、FilterGraph |
| MEDIA-PLAY | 播放器架构 | Demux、Decode、Queue、Clock、Render 和控制 |
| MEDIA-CAP | 采集与设备 | 摄像头、麦克风、屏幕采集、设备时钟和权限 |
| MEDIA-STREAM | 流媒体与传输 | HLS、DASH、RTMP、RTP、分段和自适应码率 |
| MEDIA-WEBRTC | WebRTC | SDP、ICE、DTLS/SRTP、Jitter、NACK 和 A/V 同步 |
| MEDIA-HW | 硬件编解码 | NVENC/NVDEC、QSV、DXVA、VideoToolbox、MediaCodec |
| MEDIA-GPU | GPU 媒体处理 | NV12/RGBA、Compute、Zero-Copy 和纹理桥接 |
| MEDIA-QUAL | 质量与性能 | PSNR、SSIM、VMAF、延迟、吞吐、功耗和质量档位 |

## 4. 核心基础

- 数学中的采样、卷积、频域和概率；
- 计算机科学中的缓冲、网络、实时调度和并发；
- 软件工程中的异步管线、资源生命周期和可观测性；
- 系统平台中的设备、驱动和硬件能力；
- 图形学中的颜色、纹理、显示和 GPU 处理。

## 5. 典型应用

- 本地播放器和跨平台媒体组件；
- FFmpeg 解码、处理、编码和转码；
- WebRTC 实时推流和音视频通话；
- 硬件编码、低延迟直播和远程桌面；
- 视频纹理、虚拟制作和引擎媒体集成；
- 音视频同步、Seek、丢帧和性能排查。

## 6. 来源与证据

优先来源：Codec 标准、容器规范、FFmpeg 官方源码与文档、WebRTC 标准、平台媒体文档、码流分析和可复现实验。

验证方式：

- ffprobe、码流分析和时间戳日志；
- 音视频波形、帧序列和 Clock 对照；
- 固定素材和 Golden 输出；
- 延迟、码率、质量和资源测量；
- 软硬件路径和跨平台对比；
- Seek、丢包、抖动和故障注入。

## 7. 实验与实践

- 完整 Demux→Decode→Process→Encode→Mux 流程；
- 音频 20 ms、视频 30 fps 的同步调度；
- PTS／DTS／time_base 和 Seek 实验；
- NV12、P010、RGBA 和颜色矩阵转换；
- CUDA／QSV／VideoToolbox 硬件路径对比；
- WebRTC 抖动、丢包和重传实验；
- 播放器队列、时钟和 Frame Drop 策略测试。

## 8. 核心 MOC

计划维护：

```text
音视频与多媒体总览
音视频表示、时基与时间戳 MOC
Codec、容器与码流 MOC
播放器、缓冲与同步 MOC
FFmpeg 数据流与 API MOC
WebRTC 与实时媒体 MOC
硬件编解码与零拷贝 MOC
颜色、像素格式与 GPU 转换 MOC
媒体质量、延迟与性能 MOC
```

## 9. 跨领域关系

- ← 数学：信号、采样、滤波和概率；
- ← 物理：声学和设备模型；
- ← 计算机科学：网络、实时调度和缓冲；
- ↔ 软件工程：异步架构、生命周期、测试和恢复；
- ↔ 系统平台：设备、驱动和硬件加速；
- ↔ 图形学：颜色、显示、纹理和 Compute；
- ↔ 游戏引擎：媒体播放、视频纹理和实时流；
- ↔ AI：语音、视频理解和多模态处理。

## 10. 首批建设建议

1. 媒体表示、时基、PTS/DTS 和同步基础；
2. FFmpeg Demux、Decode、Filter、Encode、Mux API 链；
3. 播放器 Queue、Clock、Seek 和丢帧策略；
4. NV12/P010/RGBA、颜色空间和 GPU 转换；
5. 硬件编解码和跨平台生命周期；
6. WebRTC 实时传输和同步；
7. 再扩展质量评估和大规模流媒体。

## 11. 非目标

- 不把平台硬件接口的安装排障复制到媒体主文章；
- 不只整理 FFmpeg 函数列表而缺少数据流和生命周期；
- 不在无素材、日志和时间戳证据时断言同步根因；
- 不把单一 Codec 或容器当作完整媒体体系；
- 不忽略颜色、时钟、缓冲和线程这些跨模块约束。
