# 01 数学领域蓝图

## 1. 领域目标

维护与具体应用无关的数学对象、结构、定理、推导、数值性质和计算方法，为图形学、AI、机器人、音视频、物理模拟和计算机科学提供共享基础。

## 2. 主归属边界

进入数学：

- 定义、定理、证明和反例；
- 线性、仿射、射影、微分和概率结构；
- 数值误差、稳定性、收敛性和优化理论；
- 与具体 API、引擎和业务无关的通用计算方法。

不进入数学：

- 投影矩阵在 GPU 管线中的使用 → 图形学；
- SE(3) 在机器人定位中的状态估计 → 机器人领域应用；
- 梯度下降在神经网络训练中的工程配置 → AI；
- FFT 库接口和平台性能 → 软件工程或系统平台。

| 代码 | 模块 | 范围 |

| MATH-FND | 数学语言、集合与证明 | 集合、关系、函数、逻辑、证明方法 |
| MATH-LA | 线性代数 | 向量空间、线性映射、矩阵、特征分解 |
| MATH-GEO | 解析、仿射与射影几何 | 坐标、标架、齐次坐标、二次曲线 |

| MATH-DE | 微分方程 | ODE、PDE、初边值问题、稳定性 |
| MATH-PROB | 概率与统计 | 随机变量、分布、估计、检验、贝叶斯方法 |
| MATH-STOCH | 随机过程与蒙特卡洛 | Markov 过程、采样、方差降低、MCMC |
| MATH-NUM | 数值分析 | 浮点、线性系统、插值、积分、误差与稳定性 |
| MATH-OPT | 优化 | 凸优化、非线性优化、约束优化、自动微分基础 |
| MATH-DISC | 离散数学与图论 | 组合、图、离散结构、递推和生成函数 |
| MATH-SIGNAL | 信号与傅里叶分析 | 卷积、频域、采样、滤波、小波 |

## 4. 核心基础

- 数学符号和证明语言；
- 向量空间、基、坐标和线性映射；
- 微积分和数值误差；
- 概率、统计和采样；
- 离散结构与复杂度意识。

当前已验证主干：点与向量、向量空间、基与坐标、矩阵、仿射空间、标架和齐次坐标。

## 5. 典型应用

- 相机、投影、几何处理和物理渲染；
- 机器人位姿、定位、SLAM 和控制；
- 神经网络训练、概率模型和生成模型；
- 音视频采样、滤波、编码和信号分析；
- 数值模拟、优化和性能误差分析。

## 6. 来源与证据

优先来源：权威教材、讲义、原始论文和标准数学参考资料。

验证方式：

- 形式推导和证明；
- 反例与边界条件；
- 数值实验和高精度对照；
- 不同表示方法的一致性检查；
- 与应用领域实验交叉验证。

## 7. 实验与实践

- 矩阵约定、基变换和数值误差实验；
- 四元数、旋转矩阵和 Lie 群一致性测试；
- Monte Carlo 估计与方差比较；
- 优化算法收敛曲线；
- FFT、采样和混叠可视化；
- 浮点精度和条件数实验。

## 8. 核心 MOC

计划维护：

```text
数学总览
线性代数与空间变换 MOC
旋转、位姿与 Lie 群 MOC
概率、采样与蒙特卡洛 MOC
数值分析与浮点误差 MOC
优化与自动微分 MOC
信号、采样与傅里叶分析 MOC
```

已实例化：数学总览、线性代数与空间变换 MOC、图形学数学基础学习路线。

## 9. 跨领域关系

- → 物理：微分方程、向量分析和数值模拟；
- → 计算机科学：离散数学、概率和算法分析；
- → 图形学：几何、投影、采样、积分和优化；
- → AI：线性代数、概率、优化和自动微分；
- → 音视频：信号、采样和频域分析；
- → 机器人：位姿、估计、优化和控制。

应用文章只展开领域上下文，不复制数学主推导。

## 10. 首批建设建议

1. 完成旋转矩阵、四元数和位姿数学；
2. 补全微积分、梯度、Jacobian 和数值微分；
3. 建立概率、采样与 Monte Carlo 基础；
4. 建立浮点、误差传播和数值稳定性专题；
5. 建立优化与自动微分基础；
6. 再扩展傅里叶分析和微分几何。

## 11. 非目标

- 不按每个应用领域复制一套数学教程；
- 不追求覆盖全部纯数学分支；
- 不把公式清单当作完整知识；
- 不在缺少真实使用目标时批量建设高阶专题；
- 不把具体库、API 和引擎实现放入数学主文章。
