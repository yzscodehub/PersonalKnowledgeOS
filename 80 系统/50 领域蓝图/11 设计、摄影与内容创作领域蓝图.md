# 11 设计、摄影与内容创作领域蓝图

## 1. 领域目标

维护视觉设计、摄影、视频、叙事、编辑和内容生产方法，提升审美判断、信息表达和多平台作品交付能力，并形成可复用的 AI 辅助创作工作流。

## 2. 主归属边界

进入本领域：

- 构图、版式、字体、色彩、视觉层级和品牌表达；
- 摄影曝光、镜头、灯光、构图、后期和作品评审；
- 视频剪辑、运动设计、声音配合、脚本和叙事；
- 内容策划、平台适配、AIGC 生产和素材管理；
- 作品分析、审美训练和创作流程。

不进入本领域：

- 图像生成、色彩管理和显示的底层渲染算法 → 图形学；
- 相机光学和传感器物理 → 物理与工程科学；
- Diffusion、LLM 和多模态模型原理 → AI；
- 产品需求和商业增长策略 → 产品与商业；
- 具体剪辑软件安装、驱动和平台问题 → 系统与平台。

## 3. 一级模块

| 代码 | 模块 | 范围 |
|---|---|---|
| DESIGN-FND | 视觉设计基础 | 点线面、节奏、比例、留白、层级和一致性 |

| DESIGN-TYPE | 字体与文字 | 字体分类、可读性、字距、层级和中英混排 |
| DESIGN-COLOR | 色彩与视觉风格 | 色彩关系、对比、情绪、系统和品牌色 |
| DESIGN-UI | UI 与交互视觉 | 界面布局、组件、状态、动效和可访问性 |
| PHOTO-FND | 摄影基础 | 曝光、焦距、景深、测光、构图和色温 |
| PHOTO-LIGHT | 光线与人像 | 自然光、布光、影调、人像和环境肖像 |
| PHOTO-POST | 摄影后期 | RAW、色彩、局部调整、皮肤、锐化和输出 |
| VIDEO-EDIT | 视频剪辑 | 镜头组织、节奏、转场、连续性和多轨编辑 |
| VIDEO-MOTION | 动效与运动设计 | 关键帧、曲线、字幕、图形动画和转场 |

| CONTENT-PLAT | 平台内容设计 | 抖音、小红书、YouTube、公众号和平台适配 |
| CONTENT-AIGC | AIGC 创作工作流 | 图像、音频、视频、提示、角色和批量生产 |

| CONTENT-CRIT | 审美训练与作品评审 | 分析框架、参考库、临摹、批评和复盘 |

## 4. 核心基础

- 视觉感知、对比、层级、节奏和一致性；
- 色彩、光线、镜头和画面组织；
- 叙事、受众、媒介和信息压缩；
- 素材、版权、版本和交付；
- AI 工具能力边界和人工审美判断。

## 5. 典型应用

- 知识类短视频、长视频和图文内容；
- 技术文章配图、演示和课程视觉；
- 摄影、人像、旅行和生活记录；
- 个人品牌、社交媒体和作品集；
- AIGC 图像、角色、动画和视频生产；
- 产品界面、三维应用和 HMI 视觉设计。

## 6. 来源与证据

优先来源：设计与摄影经典书籍、优秀作品、作者访谈、平台规范、版权许可、真实用户反馈和自己的原始素材。

验证方式：

- 同主题多方案对比；
- 设计原则与作品实例对应；
- 不同尺寸和设备可读性检查；
- 发布后的完播、停留、互动和评论；
- 同行或目标受众评审；
- 作品复盘和迭代记录。

## 7. 实验与实践

- 每日／每周作品拆解和临摹；
- 同一内容制作多种版式和风格；
- 摄影曝光、焦段、光线和构图练习；
- 剪辑节奏、字幕、声音和镜头对比；
- 书籍到脚本、图像、配音和视频的完整工作流；
- AIGC 提示、角色一致性和多场景素材实验；
- 平台发布 A/B 版本和反馈回流。

## 9. 跨领域关系

- ← 物理：光学、成像和声学；
- ↔ 图形学：颜色、显示、三维画面和图像处理；
- ↔ AI：图像、音频、视频和文本生成；
- ↔ 音视频：编码、声音、播放和媒体质量；
- ↔ 产品：受众、价值、平台和品牌；
- ↔ 人文社科：叙事、传播、文化和心理；
- → 输出：文章、脚本、视频、演示和作品集。

## 10. 首批建设建议

1. 视觉层级、版式、字体、色彩和构图；
2. 摄影曝光、焦段、光线和后期；
3. 知识视频的选题、脚本、镜头和剪辑；
4. AIGC 正式素材、角色一致性和工作流；
5. 小红书、抖音和长视频平台适配；
6. 建立作品评审、参考库和审美训练机制；
7. 再扩展 UI、品牌和复杂动效。

## 11. 非目标

- 不把软件按钮教程当作设计知识主体；
- 不只收集参考图而缺少拆解和实践；
- 不用 AI 生成代替审美判断和内容责任；
- 不在无权使用时提交网络素材；
- 不把单个平台短期流行样式当作长期设计原则。
