# 12 产品、商业与职业发展领域蓝图

## 1. 领域目标

维护发现用户价值、定义产品、验证商业模式、组织交付和发展职业能力的公开知识，帮助技术、内容和创业活动形成明确成果与长期竞争力。

## 2. 主归属边界

进入本领域：

- 产品发现、需求、定位、路线图、指标和实验；
- 商业模式、市场、增长、定价、运营和创业方法；
- 职业方向、能力模型、求职、面试、沟通和个人品牌；
- 可公开的团队协作、决策和职业复盘方法。

不进入本领域：

- 私人财务、合同、健康和具体雇佣敏感记录 → 当前公开仓库不保存；
- 通用项目执行过程 → `10 项目`；
- 具体技术知识 → 对应知识领域；
- 视觉内容生产方法 → 设计与内容创作；
- 心理、经济和社会理论本体 → 人文与社会科学。

| 代码 | 模块 | 范围 |

| PROD-ROAD | 路线图与优先级 | 目标、里程碑、机会成本和资源配置 |
| PROD-METRIC | 指标与实验 | 北极星指标、漏斗、A/B、定性和定量反馈 |

| BIZ-MODEL | 商业模式 | 客户、价值、渠道、收入、成本和护城河 |
| BIZ-MARKET | 市场与竞争 | 市场规模、竞争、趋势和进入策略 |

## 4. 核心基础

- 问题定义、目标、约束和证据；
- 用户、场景、价值和替代方案；
- 指标、实验和因果意识；
- 成本、收益、机会成本和风险；
- 沟通、写作、作品和可信度。

## 5. 典型应用

- 技术产品和个人工具的产品定义；
- AI、知识库和内容创业方向验证；
- 图形学、AI、嵌入式等职业路线选择；
- 简历、作品集、面试和 Offer 决策；
- 个人品牌、知识内容账号和公开作品；
- 一人公司、小型服务和数字产品实验。

## 6. 来源与证据

优先来源：产品和商业经典著作、真实用户访谈、市场数据、岗位说明、公司公开信息、实验结果、案例和个人公开复盘。

验证方式：

- 用户问题和行为证据；
- MVP、原型和小规模付费验证；
- 指标趋势和分群分析；
- 竞争方案与替代成本比较；
- 岗位要求、面试反馈和作品结果；
- 决策后复盘，而不是只记录事前观点。

## 7. 实验与实践

- 用户访谈、问题清单和机会地图；
- 一页产品定义、MVP 和可用性测试；
- 内容选题、标题、发布和反馈实验；
- 岗位能力矩阵、简历版本和模拟面试；
- 作品集项目和公开技术文章；
- 小型产品、咨询或知识服务验证；
- 重大职业选择的假设、结果和复盘。

## 9. 跨领域关系

- ← 各技术领域：形成真实能力、项目和作品；
- ↔ 设计与内容：产品表达、品牌和公开传播；
- ↔ 人文社科：心理、经济、传播和组织理解；
- ↔ 软件工程：产品交付、质量和迭代；
- → 项目：明确成果和时间边界的行动；
- → 责任领域：长期职业与技术能力维护；
- → 输出：简历、作品集、文章和产品材料。

## 10. 首批建设建议

1. 个人职业方向和图形学／AI 能力模型；
2. 简历、项目案例、作品集和面试体系；
3. 技术内容账号的受众、定位和输出闭环；
4. 产品发现、MVP 和用户反馈基础；
5. 一人公司与 AI 创业的小规模验证框架；
6. 再扩展市场、增长、定价和团队协作。

## 11. 非目标

- 不在公开仓库保存私人薪资、合同、身份证明和公司机密；
- 不把短期任务清单放在职业知识文章；
- 不用成功学案例替代可验证方法；
- 不在无用户和无实验时假设市场需求；
- 不把个人经历直接推广为普遍职业规律。
