# 文章原型选择指南

## 先写主问题

创建正式知识文章前，先补全：

> 本文主要回答：________。

然后选择类型：

| 主要问题 | type | 模板 |
|---|---|---|
| 它是什么、边界在哪里？ | `concept` | [[80 系统/20 模板/概念文章模板|概念文章模板]] |
| 为什么成立、如何推导？ | `theory` | [[80 系统/20 模板/理论文章模板|理论文章模板]] |
| 如何计算、步骤是什么？ | `algorithm` | [[80 系统/20 模板/算法文章模板|算法文章模板]] |
| 组件如何协作？ | `system` | [[80 系统/20 模板/系统文章模板|系统文章模板]] |
| 在某环境中如何实现？ | `implementation` | [[80 系统/20 模板/实现文章模板|实现文章模板]] |
| 接口契约和约束是什么？ | `api-reference` | [[80 系统/20 模板/API文章模板|API 文章模板]] |
| 如何验证？ | `experiment` | [[80 系统/20 模板/实验文章模板|实验文章模板]] |
| 如何定位并修复故障？ | `troubleshooting` | [[80 系统/20 模板/故障排查模板|故障排查模板]] |
| 在明确标准下如何选择？ | `comparison` | [[80 系统/20 模板/对比文章模板|对比文章模板]] |

## 不确定类型时

- 同时有两个主问题：先拆分；
- 只有来源摘录：先写来源笔记；
- 只有项目上下文：先留在项目；
- 只有一个待验证想法：先使用 `seed`；
- 只是组织多个文章：使用 `type: map`；
- 只是面向受众的成品：进入 `50 输出`。

## 模板使用规则

- 模板是问题清单，不是必须逐节填满的表格；
- 删除不适用章节；
- 可以重排结构；
- 不要为了符合模板重复同一内容；
- 新文章默认 `maturity: seed`；
- 达到 `draft` 前补足该类型的最低内容和证据要求；
- 具体要求见 [[80 系统/10 治理规则/知识对象类型与文章原型规则|知识对象类型与文章原型规则]]。

## 通用回退模板

还在探索文章问题和类型时，可以使用 [[80 系统/20 模板/知识文章模板|通用知识文章模板]]，但在进入 `draft` 前必须确定正式类型并迁移到对应原型。
