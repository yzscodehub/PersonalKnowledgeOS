# 图形学与渲染总览

图形学领域只维护图形问题、渲染算法、GPU 实现、API 映射和工程系统；通用数学基础链接到数学领域。

## 完整逻辑结构

1. 图形学基础与约定
2. 几何表示与处理
3. 相机、投影与可见性
4. 实时光栅化管线
5. 纹理、图像、采样与颜色
6. 光照、材质与 PBR
7. 阴影、透明与可见性
8. 渲染路径与材质系统
9. 抗锯齿、时域与重建
10. 后处理、成像与显示
11. 反射与全局光照
12. 体积、大气与自然环境
13. 动画、角色与特效
14. GPU 架构与并行渲染
15. 图形 API 与 Shader
16. 渲染器架构
17. GPU-Driven 与虚拟化几何
18. 性能、调试与质量
19. 光线追踪与离线渲染
20. 神经与可微渲染

## 第一阶段试点

### 图形学基础与约定

- 对象空间、世界空间、观察空间、裁剪空间、NDC、屏幕空间
- 左手与右手坐标系
- 行向量与列向量
- 矩阵乘法顺序
- 深度范围和屏幕原点约定

### 相机与投影

- Object 到 World
- World 到 View
- 正交投影
- 透视投影
- Clip Space
- 透视除法与 NDC
- 视口变换
- 深度缓冲与 Reversed-Z

### 实时光栅化管线

- CPU 到 GPU 帧流程
- 顶点输入与顶点处理
- 图元装配、裁剪和光栅化
- 透视正确插值
- Pixel Shader Quad 与导数
- Depth、Stencil、Early-Z、Blend 与 Present
