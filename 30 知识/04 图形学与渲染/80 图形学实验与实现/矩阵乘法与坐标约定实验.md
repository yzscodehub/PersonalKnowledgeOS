# 矩阵乘法与坐标约定实验

## 实验问题

验证列向量约定下的三个基础结论：

1. 平移只影响齐次分量为 $1$ 的点，不影响齐次分量为 $0$ 的方向；
2. 矩阵乘法右侧先作用；
3. 缩放后平移与平移后缩放得到不同结果。

## 假设与约定

- 使用列向量；
- 齐次点为 $(x,y,z,1)^T$；
- 齐次方向为 $(x,y,z,0)^T$；
- 组合矩阵 $TS$ 表示先缩放、后平移；
- 仅使用 Python 标准库，不依赖 NumPy。

## 实验代码

代码位于：

```text
experiments/math_graphics/coordinate_conventions.py
```

运行：

```bash
python experiments/math_graphics/coordinate_conventions.py
```

## 测试输入

点与方向使用相同前三个分量：

$$
p=(1,2,3,1)^T
$$

$$
v=(1,2,3,0)^T
$$

平移：

$$
t=(10,-2,5)
$$

缩放：

$$
s=(2,3,4)
$$

## 断言

### 平移点

$$
Tp=(11,0,8,1)^T
$$

### 平移方向

$$
Tv=v
$$

### 先缩放后平移

$$
TSp=(12,4,17,1)^T
$$

### 先平移后缩放

$$
STp=(22,0,32,1)^T
$$

并验证：

$$
TSp\neq STp
$$

## 结果

脚本由 GitHub Actions 在每次 PR 更新时运行。全部断言通过时输出：

```text
coordinate conventions: PASS
```

该结果证明了本文约定下的计算行为，但不代表所有引擎都采用相同向量侧和矩阵书写形式。换用行向量时需要同步变换公式和组合顺序。

## 工程意义

该实验可作为以下问题的最小诊断基线：

- Model 矩阵组合顺序错误；
- CPU 和 Shader 向量侧不一致；
- 方向错误受到平移影响；
- Row-Major 与行向量概念混淆；
- Scene Graph 父子矩阵顺序错误。

## 局限

- 未覆盖旋转和非均匀缩放下的法线矩阵；
- 未模拟实际 API 的常量缓冲上传和转置规则；
- 未覆盖左手与右手坐标系差异；
- 只验证数学约定，不验证具体引擎实现。

## 验证证据

- 可执行代码：`experiments/math_graphics/coordinate_conventions.py`；
- CI 断言：点／方向平移语义和矩阵组合顺序。
