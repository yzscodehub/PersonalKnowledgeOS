## 路线目标

从坐标表示开始，理解顶点如何经过对象、相机、投影、裁剪、光栅化和像素处理形成最终图像。该路线优先建立可推导、可验证的主干，而不是按 API 函数顺序学习。

## 阶段四：实时光栅化管线

## 验收方式

每个阶段至少要求：

- 能从约定推导关键矩阵或公式；
- 能用最小程序验证端点和不变量；
- 能列出 API 差异和工程失败条件；
- 能将理论文章连接到实现或实验；
- 不通过反复转置、改符号或试参数碰巧得到正确画面。
