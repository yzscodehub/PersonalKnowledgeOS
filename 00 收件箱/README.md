# 00 收件箱

收件箱是**尚未完成用途和归属判断的信息缓冲层**。它允许先捕捉、后处理，但不承担长期保存职责。

## 可以进入

- 临时问题、想法和观察；
- 待阅读链接、书目或来源线索；
- 待办线索和项目候选；
- 暂时缺少上下文、无法判断归属的记录。

## 不应进入

- 已经明确归属的正式知识、来源或项目材料；
- 长期任务清单；
- 私人、敏感或雇佣机密信息；
- 没有标题、上下文和用途的长期裸链接。

## 捕捉类型

```text
question
idea
action
source
observation
reference
decision
unknown
```

## 状态

```text
unprocessed → clarify → routed
           ↘ discarded
```

完成分流后删除捕捉笔记或移动到正式位置，不长期保留 `routed` 空壳。

## 处理时限

- 紧急行动：当天处理；
- 普通条目：一周内处理；
- 两次周回顾仍无法判断：补充上下文、转为明确问题或删除；
- 超过 30 天未处理：默认删除，除非能说明保留目的。

## 分流结果

每条内容最终进入以下位置之一：

- [[10 项目/README|项目]]
- [[20 责任领域/README|责任领域]]
- [[30 知识/00 知识总览|知识]]
- [[40 来源/README|来源]]
- [[50 输出/README|输出]]
- [[60 日记与回顾/README|日记与回顾]]
- [[90 档案/README|档案]]
- 删除

## 使用方法

1. 捕捉时只保留最小上下文；
2. 处理时补全“我保留它，是为了什么”；
3. 选择唯一主归属；
4. 把行动、来源或知识写入正式位置；
5. 删除或移动原捕捉条目。
