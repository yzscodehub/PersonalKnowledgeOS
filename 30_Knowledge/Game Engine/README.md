# Game Engine 游戏引擎

## 定位

Game Engine 是构建实时交互虚拟世界的完整软件平台。

它包含：

- Rendering
- Physics
- Animation
- Audio
- AI
- Networking
- Editor
- Toolchain

## 与其他领域关系

```text
Computer Graphics
        |
Rendering Engine
        |
Game Engine
```

## 研究方向

- Engine Architecture
- Runtime Framework
- ECS
- Resource System
- Editor
- Open Source Engine Analysis
