# Rendering Engine 渲染引擎

## 定位

Rendering Engine 是连接计算机图形学理论与工程实现的软件系统领域。

核心目标：

- 将图形学算法工程化
- 管理 GPU 资源与渲染流程
- 构建跨平台实时渲染系统
