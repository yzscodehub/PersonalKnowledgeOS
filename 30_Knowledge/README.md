# Knowledge

知识层是 PersonalKnowledgeOS 的核心。

## 设计原则

- Domain 使用树形结构组织领域。
- Knowledge Node 使用独立文件表示知识实体。
- Node 之间通过双向链接形成知识图谱。
- MOC 负责学习路径和知识导航。

## Domains

- Mathematics
- Computer Graphics
- Rendering Engine
- Game Engine
- Computer Science
- Artificial Intelligence
- Robotics
- Software Engineering
- Physics
- Design
