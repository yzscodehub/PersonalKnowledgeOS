# Metadata Specification v1.0

## Knowledge Node

```yaml
---
title:
type:
domain:
status:
---
```

## Type

- concept
- theory
- algorithm
- architecture
- api
- practice
- case
- comparison
- insight

## Status

- inbox
- learning
- understanding
- mastered
- verified
- archived

Metadata should remain minimal. Relationships should be managed through links.
