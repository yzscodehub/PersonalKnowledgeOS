# PersonalKnowledgeOS Workflow

## Knowledge Lifecycle

```text
Information
    ↓
Inbox
    ↓
Source
    ↓
Knowledge Node
    ↓
Capability
    ↓
Project
    ↓
Output
```

## Processing Rules

1. Capture first, organize later.
2. External information belongs to Sources.
3. Understood knowledge becomes Knowledge Nodes.
4. Verified abilities come from practice and projects.
5. Valuable results become Outputs.

## Principles

- Do not store raw information as knowledge.
- Do not create notes without clear purpose.
- Prefer linking over duplication.
