# Domain Template

## Purpose

Domain represents a long-term stable knowledge area.

A Domain is responsible for classification and learning navigation, not for describing all knowledge relationships.

## Structure

```
Domain
├── README.md
├── MOC.md
├── Structure.md
└── Knowledge Nodes
```

## README

Contains:

- Domain definition
- Scope
- Learning objectives
- Related domains

## MOC

Contains:

- Learning path
- Important knowledge nodes
- Cross-domain links

## Structure

Contains:

- Domain tree
- Module organization
- Node classification

## Rules

- Domain should remain stable for years.
- Cross-domain relationships should use links.
- Do not duplicate knowledge nodes only because they are used by multiple domains.
