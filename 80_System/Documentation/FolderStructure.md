# PersonalKnowledgeOS Folder Structure

## Root Structure

```text
PersonalKnowledgeOS

├── 00_Inbox
├── 10_Projects
├── 20_Areas
├── 30_Knowledge
├── 40_Sources
├── 50_Outputs
├── 60_Journals
├── 70_Capabilities
├── 80_System
├── 90_Archives
└── _Assets
```

## Design Principle

- Folder is responsible for stable classification.
- Links are responsible for knowledge relationships.
- Metadata is responsible for machine-readable attributes.
- MOC is responsible for navigation.

## Directory Responsibility

### 00_Inbox
Temporary collection area.

### 10_Projects
Goal-oriented work with clear outcomes.

### 20_Areas
Long-term responsibility areas.

### 30_Knowledge
Core knowledge assets.

### 40_Sources
External information sources.

### 50_Outputs
Created external value.

### 60_Journals
Learning records and reflections.

### 70_Capabilities
Validated abilities.

### 80_System
Knowledge base management.

### 90_Archives
Historical and deprecated content.

### _Assets
Binary resources and attachments.
