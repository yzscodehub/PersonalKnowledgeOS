# PersonalKnowledgeOS

PersonalKnowledgeOS is a long-term personal knowledge infrastructure designed for continuous accumulation of knowledge, capabilities, projects, and outputs.

## Core Goal

Build a knowledge system that can evolve for 10-20 years.

## Core Objects

- Domain: Long-term research fields
- Knowledge Node: Understandable and reusable knowledge units
- Capability: Proven abilities
- Project: Practical verification
- Output: Externalized results

## Design Principle

Stable structure, minimal metadata, dynamic linking.
