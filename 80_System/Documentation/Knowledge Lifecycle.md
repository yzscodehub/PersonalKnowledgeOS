# Knowledge Lifecycle

## Purpose

Define how information becomes reusable knowledge assets.

## Lifecycle

```
Information
    ↓
Inbox
    ↓
Source
    ↓
Knowledge Node
    ↓
Capability
    ↓
Project
    ↓
Output
```

## Knowledge Node States

```
inbox
learning
understanding
mastered
verified
archived
```

## Principles

- Reading does not equal understanding.
- Understanding does not equal capability.
- Capability requires practice and verification.
- Output represents externalized value.
